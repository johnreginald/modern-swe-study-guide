## 6. Structural additions

1. **Tooling + budget section.** FAQ: "Some cloud-based services may require subscriptions (Claude Code, etc.)". Guide never says which agent to use, sub vs API, expected weekly spend, or free options (Gemini CLI, opencode, Codex OSS).
2. **Per-week done-when checklist.** Only the capstone has gates. Each Build should end with 3-5 checkable criteria.
3. **Time estimates per item; enforce "core <= 4h".** Current W2 core: 2h podcast + HF MCP course units 0-2 (6h+) + DL.AI 11 lessons + docs = 10h+. W4 lists a 5h DHH episode. W7 PortSwigger labs are open-ended. Move overflow to optional.
4. **Session calendar.** Official Tue/Thu dates run 9/22 to 12/3. A one-page calendar lets self-studiers pace with the live course.
5. **Guest lineup table** (section 3) with closest public substitute per guest.
6. **Evals thread from W2 onward** (tool evals W2, readiness scoring W5, reviewer precision W6, eval set W10), not first introduced in W10.
7. **Prereq bridge.** FAQ: language-agnostic, Python/JS examples, CS111+. One line in "How to use".
