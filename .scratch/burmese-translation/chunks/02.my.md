## ရက်သတ္တပတ် 10 ပတ်ကို ခြုံငုံကြည့်ရှုခြင်း

| ရက်သတ္တပတ် | အကြောင်းအရာ | သင် တည်ဆောက်ရမည့်အရာ |
|---|---|---|
| 1 | ကုဒ်ရေးပေးသော ကိုယ်စားလှယ် (coding agent) များ၏ အတွင်းပိုင်းများ | ကိရိယာ (tool) 4 ခုနှင့် အပြည့်အစုံ လော့ဂ် မှတ်တမ်းတင်ခြင်း (logging) ပါဝင်သော လိုင်း 300–500 ရှိ terminal ကိုယ်စားလှယ် (agent) တစ်ခု |
| 2 | အဆင့်မြင့် နောက်ခံအချက်အလက် ဖန်တီးတည်ဆောက်ခြင်း (context engineering) | စာမျက်နှာတစ်မျက်နှာပါ စပက် (spec) တစ်ခု၊ RePPIT မှတစ်ဆင့် ဖြန့်ချိလိုက်သော လုပ်ဆောင်ချက်တစ်ခုနှင့် ကိရိယာ 2–4 ခု ပါဝင်သော MCP server တစ်ခု |
| 3 | ကိုယ်စားလှယ် ကျွမ်းကျင်မှု (skill) များနှင့် CLI | အထောက်အကူပြု script တစ်ခုပါဝင်သော ထုပ်ပိုးထားသည့် ကျွမ်းကျင်မှုတစ်ခု၊ ထို့အပြင် browser မှ မောင်းနှင်သော web ကျွမ်းကျင်မှုတစ်ခု |
| 4 | သင့်ကိုယ်စားလှယ်နှင့် ရီပို (repository) အား စိတ်ကြိုက်ပြင်ဆင်ခြင်း | ရီပို လမ်းညွှန်ချက်များ၊ ဟွတ် (hook) 2 ခု၊ နှင့် အစီအစဉ်ဆွဲသူ (planner) / အကောင်အထည်ဖော် ရေးသားသူ (implementer) / စစ်ဆေးသူ (reviewer) အဖြစ် ခွဲခြားမှု |
| 5 | ကိုယ်စားလှယ်အတွက် အသင့်ဖြစ်မှု (agent-ready) ရှိသော ကုဒ်အစုအဝေး (codebase) များ | အမှတ်ပေးထားသော အသင့်ဖြစ်မှု စစ်ဆေးခြင်းနှင့် အသစ်ဖြစ်သော ကိုယ်စားလှယ်တစ်ခုကို ကုန်ထုတ်စွမ်းအား (productivity) မြင့်မားစေသည့် ပြုပြင်မှုများ |
| 6 | ကိုယ်စားလှယ်မှ လုပ်ဆောင်သော ကုဒ်ရီဗျူး (code review) | ပူးလ်ရီကွက်စ် (pull request) များနှင့် ချိတ်ဆက်ထားပြီး PR 5 ခုပေါ်တွင် တိုင်းတာထားသော၊ ပြင်းထန်မှုအဆင့်အလိုက် စီစဉ်ထားသည့် ရီဗျူး စံသတ်မှတ်ချက် |
| 7 | လုံခြုံရေး | ခြိမ်းခြောက်မှုပုံစံ (threat model) တစ်ခု၊ CI အတွင်းရှိ SAST / SCA / လျှို့ဝှက်ချက် (secret) စကန်ဖတ်မှုများ၊ နှင့် ပရွမ့်ထဲသို့ အန္တရာယ်ရှိကုဒ်ထည့်သွင်းခြင်း (prompt injection) စမ်းသပ်မှုတစ်ခု |
| 8 | နောက်ကွယ်မှ အလုပ်လုပ်သော ကိုယ်စားလှယ် (background agent) များ | သီးခြားခွဲထားမှု၊ ဘတ်ဂျက် (budget) များ၊ မှတ်တိုင် (checkpoint) များနှင့် ထပ်မံကြိုးစားခြင်း (retry) များ ပါဝင်သော အစ်ရှူး (issue) မှ PR သို့ လုပ်ငန်းစဉ် |
| 9 | AI-native အဖွဲ့တစ်ခု တည်ဆောက်ခြင်း | မော်ဒယ် (model) ဝင်ပေါက် (gateway) တစ်ခု၊ MCP ဗဟိုဝင်ပေါက် (portal) တစ်ခု၊ နှင့် စာမျက်နှာတစ်မျက်နှာပါ လက်ခံအသုံးပြုမှု (adoption) မူဝါဒတစ်ခု |
| 10 | ဆော့ဖ်ဝဲထုတ်လုပ်ရေးစက်ရုံ (software factory) နှင့် အနာဂတ် | အကဲဖြတ်ခြင်း (eval) အစုအဝေးတစ်ခုနှင့် ထိန်းချုပ်ထားသော တိုးတက်မှု လုပ်ငန်းစဉ်စက်ဝန်း တစ်ခုပါဝင်သည့် ခြေရာခံ မှတ်တမ်းတင်ထားသော (traced) အစမှအဆုံး စက်ရုံတစ်ခု |
