## Week 8 — နောက်ကွယ်မှ အလုပ်လုပ်သော ကိုယ်စားလှယ်များ (Background Agents)

**Focus:** အချိန်ကိုက်စောင့်ဆိုင်းရန်မလိုသော မိုးတိမ်ပေါ်လွှဲပြောင်းလုပ်ဆောင်သည့် ကိုယ်စားလှယ်များ၊ ပြိုင်တူလုပ်ဆောင်သော ကိုယ်စားလှယ်အုပ်စု (fleet) များကို စီမံခန့်ခွဲခြင်း၊ အစ်ရှူး (issue) မှ ပူးလ်ရီကွက်စ် (PR) သို့ ချိတ်ဆက်သည့် လုပ်ငန်းစဉ်များ (pipelines) နှင့် Slack, Linear, GitHub တို့မှ စတင်လုပ်ဆောင်စေသည့် အစပျိုးချက်များ။

### အခြေခံကျသော သင်ခန်းစာ (Core material) (≈ 3 h 30 min)

1. **The products:** OpenAI, [Codex cloud⟦U151⟧; Anthropic, [Claude Code on the web⟦U152⟧; Cursor, [Cloud Agents⟦U153⟧; GitHub, [Managing issues and pull requests with the Copilot coding agent⟦U154⟧ (တစ်တစ်ခုစီအတွက် ≈ 20 min; ၎င်းတို့၏ အစပျိုးချက်၊ သီးခြားခွဲထုတ်မှု၊ နှင့် အတည်ပြုချက်ပုံစံများကို နှိုင်းယှဉ်ပါ)။
2. **Orchestration case study:** OpenAI, [Open-sourcing Symphony⟦U155⟧ နှင့် [Symphony specification⟦U156⟧ (≈ 60 min) — သတ်မှတ်ချက်တစ်ခုအနေဖြင့် အစ်ရှူးမှ ပူးလ်ရီကွက်စ်သို့ ချိတ်ဆက်ညှိနှိုင်းစီမံခြင်း (orchestration)။
3. **Video:** Cloudflare မှ Rajesh Bhatia, [Cloudflare's AI Engineering Stack: Assisted to Delegated⟦U157⟧ (37 min) — Cloudflare သည် ၎င်း၏ ကိုယ်ပိုင်ပလပ်ဖောင်းပေါ်တွင် အကူအညီဖြင့် ကုဒ်ရေးသားခြင်းမှ လွှဲပြောင်းလုပ်ဆောင်သော ကိုယ်စားလှယ် (agent) များဆီသို့ မည်သို့ ကူးပြောင်းခဲ့သည်များ။
4. **Durable execution:** Temporal မှ Preeti Somal, [Scaling AI Agents Without Breaking Reliability⟦U158⟧ (15 min) — ရေရှည်တည်တံ့သော အခြေအနေ၊ ချိတ်ဆက်ညှိနှိုင်းစီမံခြင်း၊ စောင့်ကြည့်မြင်တွေ့နိုင်မှု၊ အလိုအလျောက် ပြန်လည်ကောင်းမွန်လာမှု၊ လူကိုယ်တိုင် ပါဝင်ဆောင်ရွက်မှု၊ နှင့် ပြိုင်တူလုပ်ဆောင်မှုများ။
5. **Fleet operations:** Kyle Jaejun Lee, [I Run a Fleet of AI Agents Across Three Machines: Here's What Broke⟦U159⟧ (9 min) — ဂရုစိုက်နိုင်မှု ကန့်သတ်ချက်များ၊ ခိုင်မာသော နောက်ခံအချက်အလက် (context)၊ တားဆီးထားသော အတည်ပြုချက်များ၊ လမ်းကြောင်းသတ်မှတ်ပေးခြင်း (routing)၊ ပဋိပက္ခဖြစ်နေသော အလုပ်များ၊ နှင့် စက်အများအပြားတွင် ပြန်လည်ကောင်းမွန်အောင် ပြုလုပ်ခြင်း။
