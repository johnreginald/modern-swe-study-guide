### Build

သင်၏ ရီပို (repository) အတွက် စစ်မှန်သော လုပ်ဆောင်ချက်တစ်ခ ခုကို ရွေးချယ်ပါ။ ရည်ရွယ်ချက်၊ ကန့်သတ်ချက်များ၊ မပါဝင်သော အချက်များ၊ လက်ခံနိုင်မှု စစ်ဆေးချက်များ၊ ရှားပါးသော ချွင်းချက်အခြေအနေ (edge case) များ နှင့် စမ်းသပ်မှု အစီအစဉ် ပါဝင်သော စပက် (spec) တစ်မျက်နှာ ရေးသားပါ။ အဆင့်တစ်ခုကိုမျှ မကျော်ဘဲ Research → Propose → Plan → Implement → Test အတိုင်း လိုက်နာဆောင်ရွက်ပြီး အဆင့်တိုင်းမှ ထွက်ပေါ်လာသော ရလဒ်ကို သိမ်းဆည်းထားပါ။

ထို့နောက် တိကျသော ကိရိယာ (tool) ၂ ခုမှ ၄ ခုအထိ ပါဝင်သည့် MCP server တစ်ခုကို တည်ဆောက်ပါ။ ၎င်းကို MCP Inspector တွင် ဦးစွာ စမ်းသပ်ပါ၊ ထို့နောက် သင်၏ ကိုယ်စားလှယ် (agent) ထံမှ စမ်းသပ်ပါ။ ပုံမှန်အဆင်ပြေသော လမ်းကြောင်းများ၊ မမှန်ကန်သော ပါရာမီတာများ၊ ကြီးမားသော ရလဒ်များ၊ အချိန်ကုန်သွားမှုများနှင့် ခွင့်ပြုချက် အမှားများကို စမ်းသပ်ပါ။ အသစ်ဖြစ်သော ကိုယ်စားလှယ်တစ်ဦးသည် မှန်ကန်သော ကိရိယာကို ပုံမှန်ရွေးချယ်ပြီး မှန်ကန်သော အချက်အလက်များ လွှဲပြောင်းပေးနိုင်သည်အထိ သတ်မှတ်ချက် ဖော်ပြချက်တစ်ခုစီကို ပြန်လည်ပြင်ဆင်ပါ။
