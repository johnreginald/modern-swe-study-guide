## ရက်သတ္တပတ် 9 — AI-Native အဖွဲ့တစ်ဖွဲ့ တည်ဆောက်ခြင်း

**အဓိကထားမည့်အရာ:** MCP ဗဟိုဝင်ပေါက်များ (portals) နှင့် ဗဟိုချုပ်ကိုင်ထားသော၊ ခွင့်ပြုချက် (permission) လိုအပ်သည့် ကိရိယာ (tool) ရယူသုံးစွဲခွင့်၊ LLM ဝင်ပေါက်များ (gateways)၊ မော်ဒယ် (model) လမ်းကြောင်းသတ်မှတ်ပေးခြင်း (routing) နှင့် ကုန်ကျစရိတ် (cost) အကောင်းဆုံးဖြစ်အောင် ပြုလုပ်ခြင်း၊ အဖွဲ့အစည်းတစ်ဝန်း လက်ခံအသုံးပြုမှု (adoption) ပုံစံများ။

### အခြေခံကျသော သင်ခန်းစာ (core material) (≈ 3 h 40 min)

1. **ဟောပြောချက်:** Uber ၏ [Agentic SDLC: Building Blocks for Uber's Software Factory⟦U170⟧ (18 min) — မော်ဒယ် ဝင်ပေါက်များ၊ ကိုယ်စားလှယ် (agent) မည်သူမည်ဝါဖြစ်ကြောင်း သတ်မှတ်ချက်၊ PII ဖုံးကွယ်ခြင်း၊ MCP ဝင်ပေါက်များ၊ ကိရိယာ ရယူအသုံးပြုခွင့်၊ အဝေးထိန်း လုပ်ငန်းခွင်များ၊ နောက်ခံအချက်အလက် (context) ဂရပ်ဖ်များ နှင့် CI မတိုင်မီ စစ်ဆေးအတည်ပြုခြင်း။
2. **MCP ဗဟိုဝင်ပေါက်များ:** Anthropic မှ Karan Sampath ၏ [Gateways Are All You Need⟦U171⟧ (18 min) နှင့် Tobin South ၏ [What Does Enterprise-Ready MCP Mean?⟦U172⟧ (14 min) — မည်သူမည်ဝါဖြစ်ကြောင်း သတ်မှတ်ချက်၊ ဝင်ရောက်ခွင့် မူဝါဒ၊ စောင့်ကြည့်လေ့လာနိုင်စွမ်း (observability)၊ စီစဉ်ပံ့ပိုးပေးခြင်း၊ ကြီးကြပ်ကွပ်ကဲခြင်း နှင့် ဒေတာဆုံးရှုံးမှု ကာကွယ်ရေး။
3. **ဗိသုကာပုံစံ:** Cloudflare ၏ [Scaling MCP adoption: reference architecture for enterprise deployments⟦U173⟧ (25 min)။
4. **ခွင့်ပြုချက်ပေးခြင်း:** MCP ၏ [Enterprise-Managed Authorization⟦U174⟧ နှင့် [နည်းပညာဆိုင်ရာ စပက် (specification)⟦U175⟧ (20 min)။
5. **လက်ခံအသုံးပြုမှု အထောက်အထား:** DORA ၏ [2025 State of AI-assisted Software Development⟦U176⟧ (60 min) — AI သည် ပတ်ဝန်းကျင်ရှိ အင်ဂျင်နီယာစနစ်၏ အားသာချက်များနှင့် အားနည်းချက်များကို ပိုမိုကြီးမားစေသည်။ ၎င်းကို ဆန့်ကျင်ဘက် အထောက်အထားနှင့် တွဲ၍လေ့လာပါ- METR ၏ [Measuring the Impact of Early-2025 AI on Experienced Open-Source Developer Productivity⟦U177⟧ (20 min)။
6. **ဗီဒီယို:** Replit မှ Amjad Masad ၏ [The Future of Software Creation⟦U178⟧ (42 min) — ကိုယ်စားလှယ် အခြေခံအဆောက်အအုံ၊ လုံခြုံသော လုပ်ဆောင်မှု၊ ကိုယ်ပိုင်ဆုံးဖြတ်လုပ်ကိုင်နိုင်စွမ်း အဆင့်များ နှင့် စျေးသက်သာသော ဆော့ဖ်ဝဲဖန်တီးမှုသည် အဖွဲ့များကို မည်သို့ ပြောင်းလဲပုံဖော်နိုင်ကြောင်း။
