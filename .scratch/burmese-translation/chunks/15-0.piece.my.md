## သင့်တွင် အချိန်တစ်ဝက်မျှသာရှိပါက

အပတ်စဉ်ထုတ် ဗားရှင်း (build) များကို ဆက်လက်လုပ်ဆောင်ပြီး လေ့လာရန် သင်ခန်းစာများကို လျှော့ချပါ။ အောက်ပါ အနည်းဆုံး လမ်းကြောင်းကို အသုံးပြုပါ -

1. Thorsten Ball ၏ **How to Build an Agent**၊ ထို့နောက် Codex ရီပို (repository) မှ ထုတ်လုပ်မှုသုံး ပရွမ့် (prompt) ဖိုင်တစ်ခု။
2. Anthropic ၏ **Effective context engineering** နှင့် **Writing effective tools**၊ အပြင် MCP စပက် (specification)။
3. Dex Horthy ၏ **Context Engineering** တွေ့ဆုံမေးမြန်းမှု။
4. Anthropic ၏ **Claude Code best practices** နှင့် ဟွတ် (hook) ကိုးကားချက်။
5. OpenAI ၏ **Harness Engineering** ဖြစ်ရပ်မှန်လေ့လာချက်။
6. Google ၏ **Code Review** လမ်းညွှန်။
7. OWASP **MCP Top 10**၊ **lethal trifecta**၊ နှင့် PortSwigger ဓာတ်ခွဲခန်း နှစ်ခု။
8. OpenAI **Symphony** နှင့် Uber **Agentic SDLC** ဟောပြောချက်။
9. DeepLearning.AI ၏ **Evaluating AI Agents** သင်တန်း။

လက်တွေ့လုပ်ဆောင်မှုသည် လမ်းညွှန်ဖြစ်သည်။ တဖြည်းဖြည်းချင်း တိုးတက်လာသော စနစ်ကို အကောင်အထည်ဖော် ရေးသားခြင်း (implement) မရှိဘဲ ကြည့်ရှုရုံမျှဖြင့် ဝေါဟာရများကိုသာ သိရှိမည်ဖြစ်ပြီး၊ ၎င်းကို အကောင်အထည်ဖော် ရေးသားခြင်းက ဆော့ဖ်ဝဲအင်ဂျင်နီယာတစ်ဦး၏ ဆုံးဖြတ်နိုင်စွမ်းကို သင်ယူစေမည်ဖြစ်သည်။
