## Week 3 — ကိုယ်စားလှယ် ကျွမ်းကျင်မှုများ (agent skills) နှင့် CLI

**Focus:** ကျွမ်းကျင်မှု (skill) ဆိုသည်မှာ အဘယ်နည်း၊ ⟦C219⟧ နှင့် Script များသည် လုပ်ငန်းစဉ် (workflow) တစ်ခုကို မည်သို့ သင်္ကေတပြု ပုံဖော်ပေးသနည်း၊ ဝဘ်ဆိုင်ရာ ကျွမ်းကျင်မှုများနှင့် ကိုယ်စားလှယ်၏ စွမ်းဆောင်ရည်ကို ကုဒ်အစုအဝေး (repository) ပြင်ပသို့ တိုးချဲ့ခြင်း၊ CLI မှတစ်ဆင့် ထိရောက်စွာ အလုပ်လုပ်ခြင်း။

### အခြေခံကျသော သင်ခန်းစာ (core material) (≈ 3 h 40 min)

1. **Course unit:** Hugging Face၊ [Agent Skills⟦U57⟧ (≈ 60 min) — အခြားနေရာသို့ ပြောင်းရွှေ့အသုံးပြုနိုင်ပြီး လိုအပ်သလို အဆင့်ဆင့် ဖော်ထုတ်ပြသပေးသော ကျွမ်းကျင်မှုများအကြောင်း အကောင်းဆုံး စနစ်တကျ မိတ်ဆက်ထားသော သင်ခန်းစာ။
2. **Article:** Anthropic၊ [Equipping agents for the real world with Agent Skills⟦U58⟧ (20 min)၊ လက်တွေ့ အလုပ်လုပ်ထားသော နမူနာများအဖြစ် အများပြည်သူသုံး [skills repository⟦U59⟧ နှင့်အတူ။
3. **Specification + tutorial:** [Agent Skills Quickstart⟦U60⟧ (30 min)။
4. **Video:** Cursor မှ Lee Robinson၊ [The Beginner's Guide to Coding with Cursor⟦U61⟧ (45 min) — Type သတ်မှတ်ထားသော ဘာသာစကားများ၊ လင့် (lint) ပြုလုပ်ခြင်း၊ ဖော်မတ်ပြင်ခြင်း၊ စမ်းသပ်ခြင်း (test) များ၊ ဘရန့်ချ် စစ်ဆေးခြင်း (branch review) နှင့် ပြိုင်တူ နောက်ကွယ်မှ အလုပ်လုပ်ခြင်း။
5. **CLI foundation:** MIT၊ [The Missing Semester 2026: Course Overview and Introduction to the Shell⟦U62⟧ (လေ့ကျင့်ခန်းများနှင့်ဆိုလျှင် ≈ 60 min) — Shell သွားလာအသုံးပြုခြင်း၊ ပေါင်းစပ်ဖွဲ့စည်းခြင်း၊ Script ရေးသားခြင်း၊ Stream များ၊ ခွင့်ပြုချက် (permission) များ နှင့် ဘေးကင်းလုံခြုံသော Bash အလေ့အကျင့်များ။
6. **Standard:** [AGENTS.md⟦U63⟧ (10 min) — နမူနာများနှင့် သဘောတူညီချက်များကို ယခု ဖတ်ရှုပါ၊ ရီပို (repository) ဆိုင်ရာ ညွှန်ကြားချက်များသည် Week 4 တွင် အဓိက အကြောင်းအရာ ဖြစ်လာပါမည်။

### ကိရိယာ (tool) များနှင့် ကိုးကားချက်များ

- [Command Line Interface Guidelines⟦U64⟧ — ကိုယ်စားလှယ်များ (နှင့် လူများ) စိတ်ချယုံကြည်စွာ မောင်းနှင်နိုင်သော CLI များကို မည်သို့ ဒီဇိုင်းထုတ်ရမည်နည်း။ ၎င်းကို သင်၏ ကျွမ်းကျင်မှုဆိုင်ရာ ကူညီပေးသည့် Script တွင် အသုံးချပါ။
- ဝဘ်ဆိုင်ရာ ကျွမ်းကျင်မှု ကိရိယာများ: [Playwright MCP⟦U65⟧၊ [Chrome DevTools MCP⟦U66⟧ နှင့် [browser-use⟦U67⟧။
- Claude Code၊ [Common workflows⟦U68⟧ — Git အလုပ်လမ်းကြောင်း (git worktrees) များ၊ ပြိုင်တူ အလုပ်လုပ်သည့် Session များ နှင့် CLI မှတစ်ဆင့် စကားဝိုင်းများကို ပြန်လည်စတင်ခြင်း။

### အပိုဆောင်း ဗီဒီယို သင်ခန်းစာများ

- **Hands-on skills workshop:** Supabase မှ Pedro Rodrigues၊ [Skill Issue: How We Used AI to Make Agents Actually Good at Supabase⟦U69⟧ (1 h 19 min) — ⟦C220⟧၊ ပံ့ပိုးပေးသော Script များ၊ လိုအပ်သလို အဆင့်ဆင့် ဖော်ထုတ်ပြသခြင်း နှင့် လမ်းကြောင်းသတ်မှတ်ပေးခြင်း (routing) အပြုအမူများကို တည်ဆောက်ပြီး အကဲဖြတ်ခြင်း (eval)။
- **Web skills:** Browserbase မှ Paul Klein၊ [Bringing Agents onto the World Wide Web⟦U70⟧ (18 min) — Browser-agent ထိန်းချုပ်စမ်းသပ်စနစ် (harness) များ၊ ကွန်ရက်ကြားဖြတ်ဖမ်းယူခြင်း၊ WebMCP၊ Playwright CLI၊ မှတ်ဉာဏ် နှင့် ပြန်လည်အသုံးပြုနိုင်သော ဝဘ်ဆိုက် ကျွမ်းကျင်မှုများ။
- **Concept explainer:** Greg Isenberg၊ [How AI agents & Claude skills work (Clearly Explained)⟦U71⟧ (35 min)။
- **Long form:** Lex Fridman နှင့် Cursor အဖွဲ့၊ [Future of Programming with AI⟦U72⟧ (2 h 29 min) — Editor ဒီဇိုင်း၊ ခန့်မှန်းပြင်ဆင်မှုများ (speculative edits) နှင့် Cursor ပူးတွဲတည်ထောင်သူများ ကိုယ်စားလှယ်များအကြောင်း တွေးတောပုံ။
