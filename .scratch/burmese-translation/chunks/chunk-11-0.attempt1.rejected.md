## Week 9 — Building an AI-Native Team

**Focus:** MCP ဗဟိုဝင်ပေါက် (portal) များနှင့် ဗဟိုမှ ထိန်းချုပ်ထားသော ခွင့်ပြုချက် (permission) အခြေခံ ကိရိယာ (tool) ဝင်ရောက်အသုံးပြုမှု၊ LLM ဝင်ပေါက် (gateway) များ၊ မော်ဒယ် (model) လမ်းကြောင်းသတ်မှတ်ပေးခြင်း (routing) နှင့် ကုန်ကျစရိတ် (cost) သက်သာအောင် ပြုလုပ်ခြင်း၊ အဖွဲ့အစည်းတစ်ခုလုံးအတိုင်းအတာဖြင့် လက်ခံအသုံးပြုမှု (adoption) ပုံစံများ။

### Core material (≈ 3 h 40 min)

1. **Talk:** Uber, [Agentic SDLC: Building Blocks for Uber's Software Factory⟦U170⟧ (18 min) — မော်ဒယ် ဝင်ပေါက်များ၊ ကိုယ်စားလှယ် (agent) အထောက်အထား၊ PII ဆင်ဆာဖြတ်ခြင်း၊ MCP ဝင်ပေါက်များ၊ ကိရိယာ ဝင်ရောက်အသုံးပြုမှု၊ အဝေးထိန်း ပတ်ဝန်းကျင်များ၊ နောက်ခံအချက်အလက် (context) ဂရပ်ဖ်များ၊ နှင့် စဉ်ဆက်မပြတ် ပေါင်းစည်းခြင်း (CI) မတိုင်မီ စစ်ဆေးအတည်ပြုခြင်း။
2. **MCP portals:** Anthropic's Karan Sampath, [Gateways Are All You Need⟦U170⟧ (18 min) နှင့် Tobin South, [What Does Enterprise-Ready MCP Mean?⟦U172⟧ (14 min) — အထောက်အထား၊ ဝင်ရောက်အသုံးပြုမှု မူဝါဒ၊ စောင့်ကြည့်လေ့လာနိုင်စွမ်း (observability)၊ ပြင်ဆင်တပ်ဆင်ပေးခြင်း၊ ကြီးကြပ်ကွပ်ကဲမှု၊ နှင့် ဒေတာ ဆုံးရှုံးမှု ကာကွယ်ခြင်း။
3. **Architecture:** Cloudflare, [Scaling MCP adoption: reference architecture for enterprise deployments⟦U173⟧ (25 min)။
4. **Authorization:** MCP, [Enterprise-Managed Authorization⟦U174⟧ နှင့် [technical specification⟦U175⟧ (20 min)။
5. **Evidence on adoption:** DORA, [2025 State of AI-assisted Software Development⟦U176⟧ (60 min) — AI သည် ဘေးပတ်ဝန်းကျင် အင်ဂျင်နီယာ စနစ်၏ အားသာချက်များနှင့် အားနည်းချက်များကို ပိုမိုအားကောင်းစေသည်။ ယင်းကို ဆန့်ကျင်ဘက် အထောက်အထားနှင့် တွဲဖက်လေ့လာပါ: METR, [Measuring the Impact of Early-2025 AI on Experienced Open-Source Developer Productivity⟦U177⟧ (20 min)။
6. **Video:** Amjad Masad of Replit, [The Future of Software Creation⟦U178⟧ (42 min) — ကိုယ်စားလှယ် အခြေခံအဆောက်အအုံ၊ ဘေးကင်းလုံခြုံသော စေခိုင်းလုပ်ဆောင်မှု၊ သီးခြားလုပ်ဆောင်နိုင်စွမ်း အဆင့်များ၊ နှင့် သက်သာသော ဆော့ဖ်ဝဲ ဖန်တီးမှုက အဖွဲ့များကို မည်သို့ ပုံစံပြောင်းလဲနိုင်သည်များ။
