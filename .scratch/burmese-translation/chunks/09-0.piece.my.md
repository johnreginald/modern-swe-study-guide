## Week 7 — လုံခြုံရေး (Security)

**အဓိကထားမည့်အရာ:** SAST/SCA၊ မှီခိုမှုနှင့် လျှို့ဝှက်ချက် နှင့် ဝင်ရောက်ခွင့်အထောက်အထား (secret / credential) ယိုစိမ့်မှု အားနည်းချက်များ၊ ပရွမ့်ထဲသို့ အန္တရာယ်ရှိကုဒ်ထည့်သွင်းခြင်း (prompt injection) နှင့် ကိုယ်စားလှယ် (agent) သီးသန့် တိုက်ခိုက်နိုင်သော မျက်နှာပြင်များ၊ ကိုယ်စားလှယ် ကူညီပံ့ပိုးမှုဖြင့် ပြဿနာ ခွဲခြားဆန်းစစ်ခြင်းနှင့် ဖြေရှင်းပြုပြင်ခြင်း။

### အခြေခံကျသော သင်ခန်းစာ (Core material) (≈ 3 h 50 min)

1. **ခြိမ်းခြောက်မှုပုံစံ (threat model) စာရင်းများ:** [OWASP MCP Top 10⟦U126⟧ (30 min) နှင့် [OWASP Top 10 for LLM Applications⟦U127⟧ (30 min)။
2. **ကိုယ်စားလှယ် သီးသန့် ဘောင်ခတ်ကြည့်မြင်ခြင်း:** Simon Willison၊ [The lethal trifecta for AI agents⟦U128⟧ (10 min) နှင့် [Prompt injection explained⟦U129⟧ (စာသားပါဝင်သော ဟောပြောချက်၊ 15 min)။
3. **လက်တွေ့ တိုက်ခိုက်မှု:** Embrace The Red၊ [GitHub Copilot: Remote Code Execution via Prompt Injection (CVE-2025-53773)⟦U130⟧ (15 min) — ကုဒ်ရေးပေးသော ကိုယ်စားလှယ် (coding agent) ကို တိုက်ခိုက်သည့် အစဉ်လိုက် လုပ်ငန်းစဉ် အစမှ အဆုံးအထိ။
4. **ဗီဒီယို:** Semgrep မှ Isaac Evans၊ [When AI Writes Code: Rethinking App Security⟦U131⟧ (45 min) — AI ဖန်တီးပေးသော အားနည်းချက်များ၊ SAST၊ လုံခြုံရေး ကူညီပံ့ပိုးသူများ၊ တုံ့ပြန်မှု စက်ဝန်းများ နှင့် ကုဒ်ရေးပေးသော ကိုယ်စားလှယ်များ ကြောင့် ဖြစ်ပေါ်လာသော အန္တရာယ်များ။
5. **လက်တွေ့လေ့ကျင့်မှု:** Semgrep၊ [Finding vulnerabilities in modern web apps using Claude Code and OpenAI Codex⟦U132⟧ (20 min) — လက်တွေ့တွင် ကိုယ်စားလှယ် ကူညီပံ့ပိုးမှုဖြင့် ပြဿနာ ခွဲခြားဆန်းစစ်ခြင်း။
6. **ကုဒ်ရေးပေးသော ကိုယ်စားလှယ် ခြိမ်းခြောက်မှုပုံစံ:** OpenAI မှ Fouad Matin၊ [Safety and Security for Code-Executing Agents⟦U133⟧ (14 min) — အဝေးမှ ကုဒ်ပရိုဂရမ် စတင်လိုက်ပါစေခြင်း၊ ပရွမ့်ထဲသို့ အန္တရာယ်ရှိကုဒ်ထည့်သွင်းခြင်း၊ အချက်အလက် ခိုးယူထုတ်ယူခြင်း၊ ကွန်တိန်နာများ၊ ကွန်ရက် ကန့်သတ်ချက်များ၊ လူကိုယ်တိုင် အတည်ပြုချက် (human approval) များ နှင့် OS-အဆင့် ဆန်းဘောက်စ် (sandbox)။
7. **လက်တွေ့လေ့ကျင့်ခန်းများ:** PortSwigger၊ [Web Security Academy⟦U134⟧ — သွယ်ဝိုက်သော ပရွမ့်ထဲသို့ အန္တရာယ်ရှိကုဒ်ထည့်သွင်းခြင်း အပါအဝင် Web LLM attacks လက်တွေ့လေ့ကျင့်ခန်းများကို ပြုလုပ်ပါ (လက်တွေ့လေ့ကျင့်ခန်း နှစ်ခုအတွက် ≈ 60 min)။
